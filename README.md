# FitLog — Workout Library

A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## Technologies
Next.js 14 (App Router) · TypeScript · Tailwind CSS · daisyUI · lucide-react · react-hot-toast

## Features
1. Responsive workout library (3-column grid on desktop) with loading spinner
2. Sort by Duration, Calories or Rating
3. Workout details page with specs and step-by-step instructions
4. Add to today's plan (5-lift cap) or save for later, with live navbar badges and toasts
5. My Plan page with live metrics, tabs, Mark as Done and Remove
6. Toast feedback for every action
7. Custom 404 page
